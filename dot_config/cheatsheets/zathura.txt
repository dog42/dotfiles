# Zathura PDF Viewer Shortcuts
# Format: Category | Key combination | Description
# If '|' occurs in the key, escape it with '\|'.

Zathura | Ctrl + r | Toggle recolor / dark mode
Zathura | d | Toggle dual / single page view
Zathura | r | Rotate document 90° clockwise
Zathura | R | Rotate document 90° counterclockwise
Zathura | a / s | Fit to page width / fit to window
Zathura | f | Follow links in document (enter link number)
Zathura | F5 | Start presentation mode
Zathura | Tab | Toggle table of contents (index)
Zathura | / | Search in document
Zathura | n / N | Next / previous search result
Zathura | gg / G | Jump to first / last page
Zathura | [Number]G | Jump directly to page [Number]
Zathura | J / K | Scroll half page down / up
Zathura | + / - | Zoom in / out
Zathura | = | Reset zoom to 100%
Zathura | q | Quit Zathura
