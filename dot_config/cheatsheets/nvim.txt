# Common LazyVim Shortcuts (Standard Navigation & Plugins)
# Format: Category | Key combination | Description
# If '|' occurs in the key, escape it with '\|'.

nvim | <leader>ff | Find / open files (Snacks picker)
nvim | <leader><space> | Find / open files in project root
nvim | <leader>sg | Live grep across project
nvim | <leader>sw | Search word under cursor across project
nvim | <leader>, | Switch / search open buffers
nvim | <leader>/ | Grep in current buffer
nvim | <leader>e | Toggle explorer / Neo-tree
nvim | <leader>bd | Close current buffer
nvim | <leader>bo | Close other buffers
nvim | <leader>cf | Format file (Conform / LSP)
nvim | <leader>ca | Show code actions (LSP)
nvim | <leader>cd | Show line diagnostics in floating window
nvim | <leader>cr | Rename symbol (LSP)
nvim | gd | Go to definition
nvim | gr | List references
nvim | K | Show hover documentation
nvim | [d / ]d | Previous / next diagnostic (warning/error)
nvim | [e / ]e | Previous / next error
nvim | <leader>gg | Open Lazygit in git root
nvim | <leader>gl | Show git log
nvim | <leader>gb | Git blame current line
nvim | <leader>ft | Open floating terminal
nvim | <leader>xx | Trouble: show workspace diagnostics
nvim | <leader>cs | Symbols outline / document symbols
nvim | <leader>- | Split window horizontally (Split below)
nvim | <leader>\| | Split window vertically (Split right)
nvim | <leader>wd | Close current window
nvim | <leader>wm | Toggle maximize window (Zoom)
nvim | <leader>uz | Toggle Zen mode
nvim | <leader>qq | Quit Neovim (Quit all)
nvim | <S-h> / <S-l> | Previous / next buffer (LazyVim standard)
nvim | [b / ]b | Previous / next buffer
