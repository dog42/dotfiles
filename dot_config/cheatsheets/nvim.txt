# Wichtige LazyVim Shortcuts (Standard-Navigation & Plugins)
# Format: Kategorie | Tastenkombination | Beschreibung
# Falls ein '|' in der Taste vorkommt, mit '\|' escapen.

nvim | <leader>ff | Dateien suchen/öffnen (Find Files - Snacks Picker)
nvim | <leader><space> | Dateien im Root-Verzeichnis suchen/öffnen
nvim | <leader>sg | Projektweit nach Text suchen (Live Grep)
nvim | <leader>sw | Wort unter Cursor im Projekt suchen
nvim | <leader>, | Offene Buffer durchsuchen / wechseln
nvim | <leader>/ | Im aktuellen Buffer suchen (Grep Buffer)
nvim | <leader>e | Explorer / Neo-tree ein- und ausblenden
nvim | <leader>bd | Aktuellen Buffer schließen
nvim | <leader>bo | Alle anderen Buffer schließen
nvim | <leader>cf | Datei formatieren (Conform / LSP Formatter)
nvim | <leader>ca | Code Actions anzeigen (LSP)
nvim | <leader>cd | Diagnose-Meldung in Floating Window zeigen
nvim | <leader>cr | Symbol umbenennen (LSP Rename)
nvim | gd | Zur Definition springen (Go to Definition)
nvim | gr | Alle Referenzen auflisten (References)
nvim | K | Hover-Dokumentation anzeigen
nvim | [d / ]d | Vorherige / nächste Diagnose (Warnung/Fehler)
nvim | [e / ]e | Vorheriger / nächster Fehler
nvim | <leader>gg | Lazygit im Git-Root öffnen
nvim | <leader>gl | Git Log anzeigen
nvim | <leader>gb | Git Blame der aktuellen Zeile
nvim | <leader>ft | Schwebendes Terminal (Floating Terminal) öffnen
nvim | <leader>xx | Trouble: Diagnosen aller Dateien anzeigen
nvim | <leader>cs | Symbols Outline / Code-Symbole durchsuchen
nvim | <leader>- | Fenster horizontal teilen (Split Below)
nvim | <leader>\| | Fenster vertikal teilen (Split Right)
nvim | <leader>wd | Aktuelles Fenster schließen
nvim | <leader>wm | Fenster maximieren / toggeln (Zoom)
nvim | <leader>uz | Zen Mode (Ablenkungsfreies Schreiben) toggeln
nvim | <leader>qq | Neovim beenden (Quit All)
nvim | <S-h> / <S-l> | Vorheriger / nächster Buffer (LazyVim Standard)
nvim | [b / ]b | Vorheriger / nächster Buffer
