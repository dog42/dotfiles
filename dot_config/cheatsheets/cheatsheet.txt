# Personal Shortcuts & Vim Tricks
# Format: Category | Key combination | Description
# If '|' occurs in the key, escape it with '\|'.

VimTrick | *cgn n. n. | Search word under cursor, change & repeat with '.' on next matches
VimTrick | ci" / ca" | Change text inside / around double quotes
VimTrick | ci' / ca' | Change text inside / around single quotes
VimTrick | ci( / ca( | Change text inside / around parentheses (also cib / cab)
VimTrick | ci{ / ca{ | Change text inside / around curly braces (also ciB / caB)
VimTrick | ci[ / ca[ | Change text inside / around square brackets
VimTrick | cit / cat | Change HTML/XML tag content / entire tag
VimTrick | di" / da" | Delete text inside / around quotes
VimTrick | yi" / ya" | Copy (yank) text inside / around quotes
VimTrick | <C-a> / <C-x> | Increment / decrement number under cursor
VimTrick | <C-o> / <C-i> | Jump backward / forward in jump list
VimTrick | gv | Restore last visual selection
VimTrick | vip / vap | Select entire paragraph (inner / outer)
VimTrick | :%s/old/new/g | Search and replace in entire file
VimTrick | :%s/old/new/gc | Search and replace with confirmation for each match
VimTrick | zz / zt / zb | Center cursor / scroll top / bottom in window
VimTrick | H / M / L | Move cursor to top / middle / bottom of screen
VimTrick | . | Repeat last change
VimTrick | f{char} / t{char} | Jump forward to / before character {char} in line (; = repeat)
VimTrick | F{char} / T{char} | Jump backward to / before character {char} in line
VimTrick | gcc | Comment / uncomment current line
VimTrick | gc{motion} | Comment / uncomment range (e.g. gcip for paragraph)
