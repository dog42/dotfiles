# Common Yazi Shortcuts (Terminal File Manager)
# Format: Category | Key combination | Description
# If '|' occurs in the key, escape it with '\|'.

yazi | h / l | Go up directory / open file or folder
yazi | j / k | Move down / up
yazi | J / K | Jump 5 lines down / up
yazi | gg / G | Jump to top / bottom of directory
yazi | <C-u> / <C-d> | Scroll half page up / down
yazi | H / L | Jump backward / forward in history
yazi | <Space> | Select / deselect file
yazi | v / V | Start visual selection / unselect
yazi | <C-a> | Select all files in directory
yazi | <C-r> | Invert selection
yazi | o | Open file with system default application
yazi | a | Create new file or directory (end with / for directory)
yazi | r | Rename file or directory
yazi | d | Move file to trash
yazi | D | Permanently delete file
yazi | p | Paste copied files here
yazi | . | Toggle hidden files
yazi | / | Filter files in directory
yazi | f | Find file by typing (interactive search)
yazi | z | Jump directory with zoxide
yazi | Z | Jump directory with fzf
yazi | t t | Open new tab in current folder (press 't' twice)
yazi | t r | Rename current tab
yazi | 1..9 | Switch to tab 1..9
yazi | [ / ] | Previous / next tab
yazi | { / } | Swap tab with previous / next tab
yazi | <C-c> | Close current tab (or quit Yazi)
yazi | w | Show / close task manager
yazi | s | Open shell in current directory
yazi | ~ | Show Yazi help menu
yazi | q | Quit Yazi
